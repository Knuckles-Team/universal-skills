# US-SKILL-GRAPH-BUILDER — Requirements

Governing spec: [spec.md](spec.md). Delivery state is computed from `Spec:` trailers and test bindings; no file writes it.

| ID | Requirement | Acceptance |
|---|---|---|
| `US-SKILL-GRAPH-BUILDER-R001` | **The builder turns any source into a standard skill graph (rollup).** The `skill-graph-builder` skill is the only producer of the graphs in `skill-graphs`. Its CLI `scripts/generate_skill.py` classifies the sources, hands them to the pipeline and flattens the result. Children `.1` to `.4` deliver it. | See each child. |
| `US-SKILL-GRAPH-BUILDER-R001.1` | **Graph name.** Caller chain: `main` → `generate_skill`. Shape: a name that does not end in `-docs` gets the suffix, then `_portable_name` limits each path component to 80 characters with a digest. | `tests/test_skill_graph_builder.py::test_graph_name_gets_docs_suffix_and_is_portable` (bound). |
| `US-SKILL-GRAPH-BUILDER-R001.2` | **Source kinds.** Caller chain: `generate_skill` → `_classify_sources`. Shape: a comma-separated source list maps each item to a `SourceSpec`. An http(s) URL is `web`, a `.pdf` is `pdf`, other office extensions (`.docx`, `.pptx`, `.xlsx`, `.csv`) are `office`, anything else is `dir`. | `tests/test_skill_graph_builder.py::test_sources_are_classified_by_kind` (bound). |
| `US-SKILL-GRAPH-BUILDER-R001.3` | **Flat portable corpus.** Caller chain: `generate_skill` → `_flatten_reference_tree`. Shape: every `reference/**/*.md` moves to `reference/<sha256(url or title)[:8]>.md` (12 then 16 characters on a collision). `index.json` sections, `sources.json` files and the `SKILL.md` links follow the move. | `tests/test_skill_graph_builder.py::test_flatten_hashes_names_and_repoints_the_manifests` (bound). |
| `US-SKILL-GRAPH-BUILDER-R001.4` | **Output target.** Caller chain: `generate_skill` → `_resolve_out_dir`. Shape: `--output-dir` wins. Otherwise the target is `skill_graphs/skills` of the sibling `skill-graphs` checkout, so the graph is served by `SG-CONTENT-R001.2`. Without that checkout the target is `~/.cache/universal-skills/skill-graphs`. | `tests/test_skill_graph_builder.py::test_output_goes_to_the_graph_collection_or_the_cache` (bound). |
| `US-SKILL-GRAPH-BUILDER-R002` | **Web sources come from the web-crawler skill (rollup).** The `web-crawler` skill is the one page scraper of this repository; no `web-scraper` skill exists (`US-WEB-RESEARCH-R001`). The builder fetches a `web` source only through it. Children `.1` and `.2` deliver it. | See each child. |
| `US-SKILL-GRAPH-BUILDER-R002.1` | **Crawl through the skill script.** Caller chain: `SkillGraphPipeline` → `crawler_fn` from `_make_crawler_fn`. Shape: the function runs `skills/web-crawler/scripts/crawl.py` with `--urls`, `--strategy recursive`, `--output-dir`, `--max-depth` and `--max-pages`. It forwards `--disable-magic-js`, `--no-sitemap` and `--wait-for`. It returns one `AcquiredDoc` per written markdown file. | `tests/test_skill_graph_builder.py::test_web_sources_are_fetched_by_the_web_crawler_skill` (bound). |
| `US-SKILL-GRAPH-BUILDER-R002.2` | **Follow the served web operation.** Caller chain: as `R002.1`. Shape: once `crawl.py` calls `research.web` (`US-WEB-RESEARCH-R001.1`), `crawler_fn` passes `--output-dir` and the skill writes one `<sha256(url)[:8]>.md` per cited page. The page text is the stored chunk text of each cited Document (`ARBORA-OPS-R067.1`). The builder keeps no HTTP client. Depends on: `US-WEB-RESEARCH-R001.1`. | `tests/test_skill_graph_builder_served.py::test_web_source_is_built_from_research_web_documents` (planned, see test-spec). |
| `US-SKILL-GRAPH-BUILDER-R003` | **A graph records its provenance and its ontology layer (rollup).** The builder writes the records that `SG-CONTENT-R002` checks and the concept layer that `SG-CONTENT-R003` stores. Children `.1` and `.2` deliver it. | See each child. |
| `US-SKILL-GRAPH-BUILDER-R003.1` | **Provenance record.** Caller chain: `generate_skill` → `build` → `write_sources_manifest` (new, `universal_skills/skill_graph_pipeline/manifest.py`). Shape: `sources.json` holds schema `skill-graph-sources/v1`, `builder_version`, `built_at`, per-source `{kind, uri, options, extractor, fetched_at, content_hash, doc_count}` and per-file `{path, sha256, bytes}`. `SKILL.md` declares `skill_type: graph`. Depends on: `US-SKILL-GRAPH-BUILDER-R004.1`. | `tests/test_skill_graph_builder_pipeline.py::test_build_writes_manifest_and_graph_type` (planned, see test-spec). |
| `US-SKILL-GRAPH-BUILDER-R003.2` | **Ontology layer emission.** Caller chain: `generate_skill` → `build` → `write_ontology_module` (new, `universal_skills/skill_graph_pipeline/ontology.py`). Shape: when the build extracts concepts, it writes `skill_graphs/ontology/<graph>.ttl` with ontology IRI `http://knuckles.team/kg/skillgraph/<graph>`. Each class is `rdfs:subClassOf` a class of `http://knuckles.team/kg`. The file has no `owl:imports`. It sets `kg_ontology` to the file stem and lists the class IRIs in `concepts`. Without concepts both stay `null` and empty. Depends on: `SG-CONTENT-R003.1`, `SG-CONTENT-R003.2`, `US-SKILL-GRAPH-BUILDER-R004.1`. | `tests/test_skill_graph_builder_pipeline.py::test_build_writes_core_rooted_ontology_module` (planned, see test-spec). |
| `US-SKILL-GRAPH-BUILDER-R004` | **The builder runs on current owners only (rollup).** `generate_skill.py` imports the retired `agent_utilities` package, so the builder cannot run in a clean environment. The pipeline moves into this repository, and graph ingestion becomes the engine pack import. Children `.1` and `.2` deliver it. | See each child. |
| `US-SKILL-GRAPH-BUILDER-R004.1` | **Own the pipeline.** Caller chain: `generate_skill` → `SkillGraphPipeline.build`. Shape: new package `universal_skills/skill_graph_pipeline/` holds `SourceSpec`, `AcquiredDoc` and `SkillGraphPipeline` with the verbs `build` and `distill` (an extractive overview). The verbs `restyle`, `status`, `refresh` and `rebuild` move to `MEDULLA-TYPED-PACKS-R700.7` once that row lands. Depends on: `MEDULLA-TYPED-PACKS-R700.7` for those verbs. The script imports the package from there. No module of the repository imports `agent_utilities`. Refusal: the test fails on any `agent_utilities` import under `universal_skills/skills/skill-graph-builder`. | `tests/test_skill_graph_builder.py::test_builder_imports_no_retired_package`. |
| `US-SKILL-GRAPH-BUILDER-R004.2` | **Delete the daemon enrichment and the retired flags.** Caller chain: `main` → `generate_skill`. Shape: the flags `--no-kg`, `--ingest-kg`, `--append` and the `kg_enrich` argument are deleted. The builder writes the offline corpus only. The engine ingests it as a pack (`MEDULLA-TYPED-PACKS-R701`). `sources.json` keeps `kg_ingested` out. Depends on: `MEDULLA-TYPED-PACKS-R701`. | `tests/test_skill_graph_builder.py::test_retired_flags_are_refused`. |
