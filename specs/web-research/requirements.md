| `US-WEB-RESEARCH-R001` | **The web-crawler skill is a thin skill over `research.web` (rollup).** No skill named `web-scraper` exists. The `web-crawler` skill is the page scraper of this repository. It must call the arbora operation `research.web` (`ARBORA-OPS-R067`). It must hold no page fetch, render, crawl or extraction code. Children `.1` to `.5` deliver it. | See each child. |
| `US-WEB-RESEARCH-R001.1` | **Call the operation.** `universal_skills/skills/web-crawler/scripts/crawl.py` must call `research.web` through `arbora.client`. A `--query` argument maps to `query`. A `--urls` argument maps to `urls`. `--backend` maps to `backend`. The script prints the Document IDs with their citations. Proving test: `tests/test_web_research_skill.py::test_crawl_calls_research_web`. Caller chain: an agent follows universal_skills/skills/web-crawler/SKILL.md and runs `crawl.py`; `main` (universal_skills/skills/web-crawler/scripts/crawl.py:946) parses `--urls` and today drives the local crawler (:1241 builds `KGIngestor`). The target chain is `main` → `invoke` (arbora/client/invoke.py:17 in the arbora package) with the operation `research.web`. Shape: replace `main` in crawl.py with an argparse shell of about 40 lines that maps `--query`, `--urls` and `--backend` to the operation arguments and prints each Document ID with its citation; reuse `invoke` and `OperationError` (arbora/client/http.py:21) and add no HTTP client. | One script run sends one `research.web` call with the mapped arguments. Test: planned `tests/test_web_research_skill.py::test_crawl_calls_research_web` (see test-spec.md). |
| `US-WEB-RESEARCH-R001.2` | **Delete local scraping.** The skill must delete the HTTP, browser, `robots.txt`, sitemap and markdown code in `crawl.py` and `scripts/security_runtime.py`. `SKILL.md` must describe only the operation call.
