# universal-skills specifications

These specs follow the ecosystem [spec standard](https://github.com/Knuckles-Team/pipelines/blob/main/reference/spec-standard.md). One spec owns each capability. A contributor must extend an existing spec before a new one.

## Owner

This repository owns the specs with the ID prefix `US`.

## Local specifications

- [`US-PAGES`](US-PAGES-001/spec.md) — Consolidate published documentation.
- [`US-WEB-RESEARCH`](web-research/spec.md) — Web research skills call the served operation.
- [`US-MCP-BUILDER`](mcp-builder/spec.md) — The mcp-builder scaffold meets the SDK centralized-capability rules.
