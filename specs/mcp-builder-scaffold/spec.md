# US-MCP-BUILDER-SCAFFOLD — The connector scaffold declares the fleet name

Owner: universal-skills. Cross-repo IDs: `SDK-CONNECTOR-CONTROL-R071`, `PIPE-GATES-R010`.

References: [SDK-CONNECTOR-CONTROL](https://github.com/Knuckles-Team/agent-connector-sdk/blob/main/specs/SDK-CONNECTOR-CONTROL/spec.md)

## Purpose and user stories

An operator scaffolds a new connector with `mcp-builder`. The engine and arbora list the connector under its fleet name, for example `searxng-mcp`. The scaffold names the connector by that fleet name in every generated file.
